# The Great Pumpkin Reckoning 🎃

Voting site for pumpkin carving night. Everyone picks their top three pumpkins
(1st = 3 pts, 2nd = 2 pts, 3rd = 1 pt). Voting closes 23:59 UK time, Thursday 5 November 2026,
then the site reveals the 1st, 2nd and 3rd place winners.

- `index.html` – the whole site (static, hosted on GitHub Pages)
- `photos/` – the pumpkins, numbered 1–21
- `config.js` – the URL of the vote store
- `backend/Code.gs` – Google Apps Script that stores votes in a Google Sheet (setup steps are at the top of the file)
